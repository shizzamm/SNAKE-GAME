# 🐍 Snake Game

A classic **Snake Game** built using **Python** and **Pygame** with a clean interface, smooth gameplay, persistent high score tracking, and dynamic difficulty. Control the snake, collect food, grow longer, and challenge yourself to beat your highest score!

---

## ✨ Features

- 🎮 Classic Snake gameplay
- 🍎 Random food generation
- 📈 Live score tracking
- 🏆 Persistent high score system
- ⚡ Dynamic speed increase as the score grows
- ⏸️ Pause and Resume functionality
- 🎬 Start screen
- 💥 Game Over screen
- 🔄 Restart without restarting the application
- 🚧 Wall and self-collision detection
- 🎨 Clean grid-based user interface

---

## 🛠️ Built With

- **Python 3**
- **Pygame**
- **JSON** (for storing the high score)

## 🚀 Getting Started

### Prerequisites

Make sure Python 3 is installed on your system.

Install Pygame:

```bash
pip install pygame
```

---

## ▶️ Run the Game

Clone the repository:

```bash
git clone https://github.com/SharagRU/SNAKE-GAME.git
```

Move into the project folder:

```bash
cd SNAKE-GAME
```

Run the game:

```bash
python snake_game.py
```

---

## 🎮 Controls

| Key | Action |
|------|--------|
| ↑ | Move Up |
| ↓ | Move Down |
| ← | Move Left |
| → | Move Right |
| Space | Pause / Resume |
| R | Restart after Game Over |
| Q | Quit after Game Over |

---

## 🎯 Gameplay

- Press any key to start the game.
- Guide the snake using the arrow keys.
- Eat the food to increase your score.
- Each food item makes the snake move faster.
- Avoid hitting the walls.
- Avoid colliding with your own body.
- Try to achieve the highest score!

---

## 🏆 High Score

The game automatically saves your highest score in:

```text
snake_highscore.json
```

Your best score is preserved even after closing the game.
