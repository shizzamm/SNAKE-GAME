# SNAKE-GAME
Developed a fully functional Snake Game using Python , implementing core game mechanics such as movement control, collision detection, score tracking, and increasing difficulty.
run python snake_game.py in cmd under this file and press any key to start
controls>>>
up key-for moving the snake up
right key- for moving te snake to right
left key-for moving the snake to left
when it toches the edge the game is over
press Q or close button to quit the game
press R to restart the game again
